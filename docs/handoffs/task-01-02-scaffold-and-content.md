## What was done

### Task 1 — scaffold
- npm workspaces monorepo (`apps/*`, `workers/*`). pnpm was dropped because Node 26 no longer bundles corepack.
- `apps/web`: Vite 8, React 19, TypeScript strict (plus `noUncheckedIndexedAccess`), Tailwind v4 via `@tailwindcss/vite`, vite-plugin-pwa (autoUpdate, precaches js/css/html/svg/webp/mp3), i18next with `en`/`zh` (choice saved in localStorage, default `en` until Yang decides), Vitest (jsdom), Playwright (desktop Chrome + Pixel 7).
- ESLint flat config (typescript-eslint, react-hooks), Prettier, `.editorconfig`, `.gitignore`.
- CI: `.github/workflows/ci.yml` runs lint, format check, typecheck, unit tests, content validation and build, then e2e.

### Task 2 — content
- `apps/web/src/content/schema.ts` defines Zod schemas for chapter, word and track. Objects are strict (unknown keys rejected), all three languages are required, and `tema` and `reviewed` are added.
- `apps/web/src/content/validate.ts` holds the CLAUDE.md §6 rules as pure functions: `checkChapter` and `checkTrack`.
- `scripts/validate-content.ts` is the CLI. Missing media is a warning normally. `--strict` (production) fails on missing media **or** any `reviewed: false` chapter.
- `content/tahun-3/` contains `track.json` and Units 1–3, with 12 words each. Yang reviewed the BM and approved it (`reviewed: true`).
- `content/tahun-3/image-prompts.json` holds the image prompts. Images are being generated by Codex in a separate process, so ignore missing PNGs.

## Decisions worth challenging
1. `containsPhrase` treats `-` as part of a word, so `saudara` does **not** match inside `saudara-mara`. Is that the right behaviour for BM reduplication?
2. The jumbled-sentence check is only "the joined tiles contain the word". The game will check the child's answer against this single canonical order, even if other orders are also valid BM.
3. The word-class check on distractors only works for distractors that are also words in the same chapter (warning only).
4. Media files are named `<id>.webp` / `<id>.mp3`, enforced by the schema and checks.
5. The audio/TTS step doesn't exist yet. The plan's per-example audio (`<id>-example.mp3`) is not in the schema.
