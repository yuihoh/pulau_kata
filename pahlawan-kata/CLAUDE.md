# 词语勇士 Pahlawan Kata

手机上的 RPG，帮助 9–12 岁孩子学 **Bahasa Melayu** 生字，内容对接 **KSSR Bahasa Melayu Tahun 4 SJK** 课本。
玩家选男 / 女勇士，打怪（认字、测验、语法、造句、复习）、升级、收集装备、换装。

## 不能违反的规则

1. **要学的语言永远是国语。** 中文 / 英文只用来帮助理解：界面、意思、规则、反馈。题目选项永远是国语。
2. **不复制课本内容**：课文、诗歌、歌词、插图都有版权（KPM / DBP）。可以用的只有 Tema / Unit 名称、语法点、单词。例句和题目都要自己写。
3. **所有界面文字走 i18n**（`zh` / `en`），不写死在组件里。内容数据里每条都要有 `zh` 和 `en`。
4. **学习优先**：
   - 装备不能减少题数。
   - 用了提示才答对 → 该字标记"需复习"，不算掌握。
   - "掌握度"只算不用提示答对的字。
5. **儿童产品**：
   - 不设真钱抽卡 / 真钱买装备或外观。
   - 账号由家长建立。
   - 不收集不必要的个人资料。
6. **还没决定的事**（见设计文档第 16 节"还要决定"）：**不要自己定，先问 Yang。**

## 已决定的数值（快速参考）

| 项目 | 数值 |
|---|---|
| 结构 | 8 Tema（王国）× 3 Unit（区域）；每个 Unit：认字 → 测验 → 语法 → 造句 + 可选秘境；Tema 结局：补救 / 练习场 / Boss / 挑战 |
| Tema 解锁 | 一开始全开放；Unit 内 4 关照顺序；3 个 Unit 都完成才能打 Tema Boss |
| 难度 | 初级 A 包 12 字 · 每题 20 秒；中级 A+B 24 字 · 15 秒；高级 A+B+C 36 字 · 12 秒 |
| 测验 | 每个词包一轮，10 题；基础生命 3 |
| 积分 | 答对 10；不用提示 +5；连对 3 题起每题 +2；难度 ×1 / ×1.5 / ×2；学校进度 Tema ×2 |
| 刷分限制 | 同一关每天前 3 次全分，之后半分；复习到期字和弱字永远全分 |
| 等级 | Lv 1–30，每级 1 属性点：体力（每 5 点 +1 生命，上限 +3）/ 专注（每点 +1 秒，上限 +10）/ 智慧（每 4 点 +1 提示，上限 +3） |
| 间隔重复 | Leitner 5 盒：当天 / 1 天 / 3 天 / 7 天 / 14 天；不用提示答对升一盒，答错回第 1 盒，用提示留原盒 |
| 武器 | 剑（连击积分 +50%）和法杖（+1 提示）在创建角色时二选一；弓（每题 +3 秒）Lv 5；锤（开局护盾）Lv 10 |
| 阶级 | 完成 Tema：初级 → 铜，中级 → 银，高级 → 金；第一次用中级 / 高级完成任何 Tema → 解锁骑士 / 传奇外观 |
| 换装 | 装备（能力）和外观（样子）分开，有"只换样子"开关；叠层 z 值见美术文档 13.2 |

## 技术方向（建议，开工前先跟 Yang 确认）

- **前端**：React + TypeScript + Vite，做成 PWA（先用手机浏览器测试，之后可包成 App）
- **状态**：Zustand；**i18n**：i18next（`src/i18n/zh.json`、`en.json`）
- **后端**：Supabase（家长账号、孩子档案、进度、`word_progress`）
- **动画**：CSS / Framer Motion 就够，暂时不需要游戏引擎
- **内容**：`content/tahun4/t{N}_u{N}.json`，按 `data/schema/unit.schema.json` 校验
- **美术**：`assets/` + `assets/manifest.json`（格式见美术文档第 13 节）。真图到之前，先用原型里的 SVG 当占位

建议的代码结构：

```
src/
  app/          路由、页面（对应 prototype 的画面）
  game/         战斗引擎、计分、Leitner、解锁规则（纯函数，要有单元测试）
  content/      读取和校验词库
  avatar/       纸娃娃叠层组件（按 manifest 组合）
  i18n/
  services/     Supabase
content/tahun4/
assets/
```

## 视觉

- **颜色**：navy `#232A5C`、ink `#1E2033`、amber `#FFB020`、teal `#1FA39A`、coral `#E5533D`、blue `#2F7DE1`、purple `#8B4FD8`、cream `#FFF6E5`
- **稀有度颜色**：普通 `#8A8F98`、稀有 `#2F7DE1`、史诗 `#8B4FD8`、传说 `#E0A200`
- **字体**：标题 ZCOOL KuaiLe；中文正文 Noto Sans SC；国语 / 英文和数字 Baloo 2
- **手机竖屏 390×844 为基准**；按钮触控区 ≥ 44px

## MVP 范围

1. 登入（家长）+ 孩子档案 + 创建角色（男 / 女、颜色、剑 / 法杖、语言）
2. 分级小测验 → 建议难度
3. 世界地图 → **Tema 1** 的 3 个 Unit × 4 关 + 秘境 + Tema 结局（初级 + 中级）
4. 战斗系统（生命、计时、提示 / 暂停 / 护盾）、结算、宝箱、升级
5. 衣柜（战袍颜色 + 剑 / 法杖）、积分与掌握度、每日复习
6. 中文 + 英文界面

**建议的第一步**：先写 `game/` 的纯逻辑（计分、Leitner、解锁、难度词包）和单元测试，再做画面。
